# Kelly Jelly v2.7.5 — Game speed hotkeys

1 / 2 / 3 select x1 / x2 / x3 for the whole combat simulation. Numpad 1–3 also work. Key releases, repeats and modified shortcuts do not switch speeds. Selection is available during play and pause; pausing never starts combat. Speed keys are reserved from rebinding, and old conflicting custom bindings fall back to defaults.

Engine time scale and physics tick rate increase together, retaining a 1/60-second simulated physics step. Existing damage formulas and movement speeds in game units are unchanged. Game time, waves, enemies and projectiles run faster in real time. The existing clock displays x2/x3 with a slightly smaller font; x1 keeps the original clock layout. No separate HUD widget.

Interface, rewards, level celebration and death animation use normal speed. The selected speed resumes with combat; new runs start at x1. Returning to the menu resets the engine time scale and physics rate. Audio playback speed is unchanged.
