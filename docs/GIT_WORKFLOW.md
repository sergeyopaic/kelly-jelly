# Git в Kelly Jelly

Локальный репозиторий создан при подготовке к Steam 7 ноября 2026. Включены исходники v2.7.5, необходимые ассеты, тесты, документы и аудит. Сборки и ZIP сохранены на диске, но в Git не входят. Историю более ранних версий из ZIP автоматически не реконструировали.

## Ежедневная работа

1. Перед изменением посмотреть `git status` и создать небольшую ветку задачи.
2. Сделать одно связное изменение, проверить его, просмотреть `git diff`.
3. Добавить только относящиеся к задаче файлы; сделать коммит с описанием результата.
4. Для выпуска: зафиксировать коммит, выполнить нужные проверки, собрать EXE и записать SHA256 и версию движка.
5. Сохранять сборку отдельно от исходников; отметить соответствующий исходникам тег.

Кэш Godot, экспортные шаблоны, build, ZIP, логи, секреты и приватная сборка презентации исключены в .gitignore. UID Godot, сцены, скрипты, исходные изображения и лицензии шрифтов входят в историю. Генераторы ассетов не заменяют сохранение самих ассетов: внешний сервис может изменить доступность.

## Удалённый репозиторий

Origin пока не назначен. GitHub-поиск обнаружил публичные teslasolar/JellyKelly (HTML-проект) и teslasolar/kelly (пустой), однако связь с текущими исходниками не доказана. Не используем их как адрес отправки без подтверждения владельца. Рекомендуется отдельный приватный репозиторий для актуальной Godot-игры; опубликовывать код для релиза в Steam не требуется.

После выбора адреса: проверить владельца и видимость, подключить origin, отправить main, затем проверить восстановление из чистого clone. Только локальная папка .git не защищает от поломки диска. Секреты SteamPipe и ключи хранить отдельно; удалять опубликованные ключи из последнего коммита недостаточно, их нужно отзывать.

Лицензию собственного кода и режим публикации выбирает владелец. Факт использования открытого движка не делает автоматически открытыми игру и ассеты.
