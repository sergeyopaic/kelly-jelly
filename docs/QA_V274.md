# Kelly Jelly v2.7.4 — Final-heart melting animation

At zero HP the run is recorded immediately and combat stops. Kelly holds a hurt expression briefly, sinks and widens into a matte candy puddle, then holds the final puddle before the result screen opens. Total duration: 1.35 seconds. The puddle follows the selected skin. Rendering uses the existing hurt frames plus a procedural puddle; no generated assets or new controls.

The death timer runs separately from gameplay. Movement, dash, impact shake, pickup collection, enemy simulation, projectiles and run time stop. Fatal contact exits the current simulation tick before pickups, so nearby hearts cannot revive a finished run. Death does not grant pending absorption. The result notification emits exactly once after the animation, while the run record is saved immediately. Manual end remains immediate and nonfatal damage retains the ordinary hurt behavior. New runs reset the animation.
