## Проверка сборки перед отправкой

- Чистая Windows-машина, без Godot и без исходников: установка из Steam, первый запуск, завершение, повторный запуск.
- Клавиатура/мышь и реальный контроллер: полное меню, перепривязка, потеря фокуса, подключение/отключение.
- Здоровье 1→0: бой заморожен, таяние закончено, результат один раз; новая попытка чистая.
- Повторные уровни, босс во время смерти, reward + level-up одновременно: ни один экран не блокирует управление навсегда.
- ×1/×2/×3: совпадают правила столкновений, ресурсы и форма телеграфа; нагрузка проверена на слабом ПК.
- Время 1:30, рост массы, очень долгий забег: нет скачков сложности из-за времени на ускорении.
- Настройки громкости, тряски и вспышек сохраняются; важное видно не только цветом и не только слышно.
- Профиль/backup/обновление/новый пользователь: нет потери прогресса или записи в папку установки.
- Release из зафиксированного коммита, записаны Godot/export-template, версия, дата, SHA256 и результат тестов.
- Удалены тестовые capture-аргументы из launch options; лицензии/поддержка доступны в поставке.

## Задача по лицензиям, найденная в аудите

В последних папках сборок и ZIP — только EXE; отдельный GODOT_LICENSE.txt есть в более старых сборках. В текущих титрах найдена короткая строка «Godot Engine (MIT)», а не полный текст или ссылка на лицензию. Нужно проверить наличие notices внутри реальной поставки и оформить доступный игроку комплект: Godot MIT, third-party notices, OFL шрифтов, реестр PixelLab. Само наличие манифеста генераций не доказывает коммерческие права. Не менять лицензию собственного кода без решения владельца.

Основание: [официальное руководство Godot по лицензиям](https://docs.godotengine.org/en/stable/about/complying_with_licenses.html). Это задача проверки документов, не заключение о правовом статусе всей игры.

## Что не делать до подтверждения ядра

Не начинать мультиплеер, десятки биомов, экономику с покупками или обязательный ежедневный гринд. Не обещать Steam Deck Verified и полную поддержку контроллера по одному наличию кода. Не покупать трафик на страницу, которая ещё не показывает отличие тарана. Не ставить дату выпуска ради минимального таймера Valve. Не менять согласованные правила поглощения незаметно под видом полировки.
